This repository contains academic lab work exploring Retrieval-Augmented Generation (RAG), AI agents, and tool-based workflows. The labs demonstrate how agents can use additional information sources and tools to build context for answering user queries, along with retrieval, embeddings, document processing, and LangChain components. The work includes experimentation with tools such as Tavily, Wikidata, AWS Bedrock, and other supporting libraries. This repository is intended to demonstrate coursework and learning in RAG and agent-based AI systems.
