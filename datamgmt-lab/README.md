This repository contains academic SQL database lab work based on an inventory management system for Zhan's Gourmet Goodies Bakery. The project covers database normalization, relational schema design, primary and foreign keys, table creation, data population, and relationships between employees, products, ingredients, suppliers, procurement, recipes, and bakery locations. SQL queries are also used to generate business-oriented reports using joins, grouping functions, aggregate functions, and subqueries. This repository is intended to demonstrate coursework and practical learning in relational database design and SQL.
